Entendendo Decorators em Python

Escrito por {{ nome }}

Decorators são um dos recursos mais poderosos e elegantes da linguagem Python. Eles permitem que você modifique o comportamento de uma função ou classe sem precisar alterar o código original delas.

Como funcionam?

Em essência, um decorator é uma função que recebe outra função como argumento e retorna uma nova função. Isso é muito útil para coisas como verificação de autenticação, logs, ou medição de tempo de execução.

@meu_decorator
def minha_funcao():
    print("Executando a função!")

Se você está construindo uma API com ferramentas modernas de backend, certamente vai se deparar com esse padrão na hora de criar rotas de acesso.
